# RTConnect: Sistem Informasi Administrasi RT/RW Terintegrasi Generative AI & NLP Chatbot

Sistem informasi pelayanan administrasi digital di tingkat Rukun Tetangga (RT 032 RW 08 Griya Taman Asri) berbasis web (Python Flask) yang mengintegrasikan:
1. **Generative AI:** Otomatisasi perumusan draf surat pengantar formal berdasarkan masukan warga.
2. **NLP Chatbot (RAG):** Layanan informasi tanya jawab 24/7 berbasis *Retrieval-Augmented Generation* dan dokumen regulasi resmi RT dengan kemampuan eskalasi langsung ke WhatsApp Ketua RT.
3. **Pengesahan Hibrida:** Opsi tanda tangan digital terverifikasi QR Code dan tanda tangan basah fisik.
